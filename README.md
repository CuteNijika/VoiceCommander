# 小月同学 VoiceCommander

> 用语音控制卫月插件：先说唤醒词，再说命令词，插件自动帮你执行对应的游戏内指令。
> 全程离线，音频只在本地处理，不上传任何数据。

**作者**：CuteNijika

---

## ✨ 功能

- 🎙️ **说话执行命令**：说「打开卫月」→ 自动执行 `/xlplugins`，和手打命令完全一样
- 🔑 **唤醒词防误触发**：默认先喊「你好卫月 / 小月同学」才会听命令，闲聊 100% 安全（也可开免唤醒模式）
- 📝 **一行多说法**：`打开卫月,关闭卫月 → /xlplugins`，同义说法写一行即可
- ↔️ **拖动排序**：命令优先级随手调
- 🎚️ **可选麦克风**：多设备时自由指定用哪个麦识别
- ⚡ **完全离线**：基于 Windows 自带语音识别引擎，无需联网、无需 API Key

## 📥 安装

1. 打开游戏，输入 `/xlsettings`
2. 找到**实验性功能**区块 → **自定义插件仓库（Custom Plugin Repositories）**
3. 粘贴本仓库 `repo.json` 的链接：`https://raw.githubusercontent.com/CuteNijika/VoiceCommander/main/repo.json`
4. **⚠️ 必须把这条仓库前面的框打上勾**（很多人漏了这步导致搜不到插件）
5. 保存，然后 `/xlplugins` → 搜索「小月同学」→ 安装并启用

## ⚠️ 使用前必读（重要）

### 1. 电脑必须有「中文语音识别」组件

本插件依赖 Windows 自带的中文语音识别引擎。**简体中文版 Win10 / Win11 一般自带**；
但以下情况**大概率没有**，装了插件也无法识别中文：

- 英文版 / 其他语言版 Windows
- LTSC / 精简版 / 优化版系统
- 部分国产魔改系统

**检查方法**：游戏内输入 `/vc status`，看「系统识别引擎」里有没有 `zh-CN`。
**没有怎么办**：Windows 设置 → 时间和语言 → 语言和区域 → 中文 → 语言选项 → 勾选安装「语音识别」。

### 2. 麦克风权限与设备

- Windows 设置 → 隐私 → 麦克风 → 允许**桌面应用**访问麦克风
- 多麦克风设备（蓝牙耳机 + 独立麦等）时，在插件设置窗口的「识别用的麦克风」下拉框里**选你说话的那个**

### 3. 升级不会丢设置

插件升级只替换程序文件，你自定义的唤醒词、命令映射等全部保留。
**例外**：卸载插件时若勾选「同时删除配置」，设置才会被清空。

## 🚀 快速上手

1. `/xlplugins` 里启用插件后，聊天框会显示加载回执
2. 对麦克风说：**「你好卫月」**→ 看到「已唤醒」提示
3. 接着说：**「打开卫月」**→ 插件中心弹出来了，恭喜跑通！

### 默认命令表

| 说出来的话 | 执行的指令 |
|---|---|
| 打开卫月 / 关闭卫月 | `/xlplugins` |
| 打开卫月设置 / 关闭卫月设置 | `/xlsettings` |
| 打开卫月日志 / 关闭卫月日志 | `/xllog` |
| 打开小月同学 / 关闭小月同学 | `/vc ui`（本插件设置窗口） |
| 飞行到标记位置 | `/vnav flyflag`（需装 vnavmesh） |
| 走到标记位置 | `/vnav moveflag`（需装 vnavmesh） |

唤醒词、命令映射、置信度全部可在 `/vc ui` 里自定义。

## 📖 指令一览

```
/vc            开关麦克风监听
/vc ui         打开设置窗口
/vc status     查看运行状态与诊断信息
/vc wake 词1,词2   设置唤醒词
/vc add 说法|指令  添加命令映射
/vc del 说法       删除命令映射
/vc run 说法       不开麦直接执行某条映射（测试用）
/vc list       查看全部唤醒词与命令映射
/vc reload     重启识别引擎
/vc sleep      强制回到休眠
```

## ❓ 常见问题

**Q：装好了但说话没反应？**
按顺序排查：① `/vc status` 看引擎是否运行、错误信息是什么 → ② 引擎列表没有 `zh-CN` 就去装中文语音识别（见上文必读第 1 条）→ ③ `/vc run 打开卫月` 测命令链路 → ④ 检查麦克风是否被别的软件（QQ、Discord）独占。

**Q：唤醒了但识别不准？**
设置窗口里调高「引擎拒识阈值」和「识别置信度下限」；说话离麦别太远；唤醒词建议用 3~4 个字（太短容易被环境噪音误触发）。

**Q：打本时怕误触发？**
保持默认的唤醒词模式（不要开免唤醒），打本时队友喊话不会被当成命令。

**Q：会录音上传吗？**
不会。识别用的 Windows 本地引擎，音频全程不离开你的电脑，插件没有任何联网请求。
